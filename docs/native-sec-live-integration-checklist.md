## Actual process and failure behavior

The host starts observation independently of capture. It waits for a validated native prefix, then launches capture in another process so quote/upload waits and synchronous recovery work cannot block the watcher event loop. Capture readiness has a 10-second/100-poll budget; capture has a 540-second ceiling, then TERM and a two-second hard-stop fallback for its own worker only. Source observation retains its existing configured session/deadline; the host does not shorten or cancel it. Health is written at the natural producer boundary, including producer exit, capture result, byte counts and complete-bundle state. Capture storage is capped at 400MiB/4096 files and process output at 2MiB per process. Existing producer/native archive bounds remain separate; this is not a cap on all pre-existing repository datasets.

Before each capture client call, the worker revalidates the input/binding/extra-source pins; the existing wrapper checks source HEAD, workflow, references, runtime dependencies, approval and history. Synthetic references and mode are mandatory. Adding credentials cannot select a live mode. The host does not install or dispatch anything and does not inherit arbitrary parent environment credentials.

After natural producer completion, a dedicated bundle can be prepared only if original native records, source status, final snapshot and every configured minute 09:30–15:00 pass. It contains exact original bytes, not reconstructed timestamps. It may be passed to a reviewed publisher interface as `native-sec-complete-run-v1` with seven-day retention. An upload ACK is not independent verification; the next lookup rechecks GitHub metadata, the ZIP digest, original bytes and terminal-run metadata. Missing publication stays explicitly unavailable. 15:00–16:00 remains unmonitored; configured completeness is not a full-session claim.

Selection is deliberately conservative: an incomplete latest attempt, truncated history, tied latest timestamps or ambiguous artifacts block capture instead of silently falling back to an older archive. This can leave history unusable even when an older run is complete. The available-parent scope and continuity gaps remain explicit. Producer source must match run HEAD or a separately supplied independent per-run source pin, as well as the reviewed source list; an artifact cannot choose its own trusted source. Staging refuses overwrite and preserves interrupted bytes. No source proof or first-ever ingestion is invented.
