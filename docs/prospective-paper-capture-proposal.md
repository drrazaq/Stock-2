## A specific hypothesis and a deliberately small population

Hypothesis: the existing discovery stream's first authenticated SEC filing observations have positive **30-minute candidate minus contemporaneously matched-control net return**, after the unchanged costs. This is a test of whether that existing discovery lane contains information at all, not an assumption that filings are good news. The existing lane is not a validated 30-minute trading strategy; its registered broader horizon does not prove this hypothesis. A filing's existence, missing CIK or generic form name does not establish debt, dilution, resale or bullishness. No materiality/positive-news classifier, target, stop or new price-momentum selector is introduced.

Fixed candidate AND control universe for this minimal calibration: **AMD, INTC, NVDA, AMAT, LRCX, KLAC**, active US common shares only, current ZAD PASS. This is a six-name methodological test, not representative small-cap, premarket or whole-market coverage. No substitute is added if one fails. Industry equality is the authenticated four-digit SEC SIC code as known before detection; these names are NOT presumed to share one industry. If the actual mappings produce no eligible pair, enrollment blocks and the calibration reports that failure.

Enroll the first eligible original SEC_EVENT observation per security/day, within the declared window, with namespace SEC, original eventId, SEC accession and source-content revision SHA256. Preserve all repeats, conflicts, non-SEC, late, unknown and excluded observations as labelled research context. Record the actual paper handoff clock separately from the original discovery clock. If an earlier captured quote exists after detection but before the event was handed to paper capture, retain the event as LATE_EVENT_HANDOFF_NO_RETROSPECTIVE_ENTRY; do not select that earlier quote as an entry. A normal first handoff at the first post-detection snapshot remains eligible. A conflicting event ID quarantines both versions. An observation first ingested before this window cannot be deferred and presented as newly discovered at the open. Retain the full original source envelope/bytes and detection latency. Unknown identity or ZAD blocks enrollment/approved BUY; research survives. This does not alter any frozen model's enrollment or scorecard.

Why evaluate: the lane and point-in-time paper matcher already exist, and paired evidence would answer a currently unanswered question with little extra machinery. No historical positive result is claimed. A short session may contain **zero eligible events**; that is a valid calibration outcome, never permission to manufacture an event or loosen the rule.
