# EXEC04 current broker mutation fault matrix

Scope is every currently wired broker mutation, not every repository side effect or authorization to trade. Source inventory: only scan.mjs consumes paperRequest; POST entry, POST exit and DELETE existing order use the same alp wrapper. paper-transport pins PAPER origin (localhost test only), strict default-off opt-in, schemas and bounded no-redirect/no-retry I/O. options-lab/squad15/squad15b trade-host paths are contract/clock/calendar GETs; probe asset requests are GETs. No workflow sets STOCK2_ENABLE_PAPER_ORDERS. Regression forbids a new unreviewed adapter consumer or order endpoint/activation path.236 baseline source/HTML files matched actual remote blobs except intended current scan changes; protected data/keys untouched.

| Route | Before request | After response | Restart/race faults |
|---|---|---|---|
| POST buy limit+OTO | Current adapter schema, literal opt-in, trusted runtime, private intent CAS+readback | Matching broker UUID/symbol/side/client ID and private ACK CAS+readback | Lost reservation/ACK, unknown broker response, redirect,500/429, malformed/hung body, changed content and concurrent actors block replay |
| POST sell market | Same guard; current caller requires confirmed open-order/cancel evidence | Same order identity ACK | Same faults; caller test proves failed cancellation intent cannot proceed to a sell |
| DELETE order UUID | Same guard; valid exact ID path/no body | HTTP204 or matching canceled record plus durable journal ACK | Same faults/duplicate suppression; unknown cancel prevents follow-on order |

Private store uses conditional GitHub contents writes to the existing drrazaq/stock-2-private-data repository, data/broker-intents/<opaque hash>.json on its existing main data branch. Hash includes nonpublic account identifier; record has only hashes,status,time,broker UUID, no order payload/amount/token. It is never public. Missing token, permission/readback/refusal, changed SHA or unconfirmed commit blocks before broker; post-broker state uncertainty stays quarantined. A recorded ACK is not resent; automatic reconciliation/order replacement is not invented. Future authorized operator can inspect broker status read-only using the retained private UUID before any reviewed manual resolution.

No new permission/secret/binding or real private-repository write was made. Source is development-branch only; user approval is still required to deploy and enable any real/paper order and associated private-intent writes. Default remains off; inherited order-enable environment flag is not changed by this work. Actual broker fill quality and strategy plans are not certified by EXEC04. EXEC03, ZAD04 and prospective profitability remain separate open requirements.

Evidence: eleven journal/composition/source-inventory contracts, six adapter contracts and seven localhost caller fault contracts. All methods test default/config failures, durable reservation/ACK loss, unknown outcomes, independent-job races/restarts and body/redirect/timeout faults without any external broker call.
