R1 data key tool (offline)

Runs only on this device; it cannot connect to anything. Nothing is saved. Close the page when done.

1. Make a new key

32 random bytes from this device's secure random generator, shown as 64 characters 0-9, a-f. Copy it into your password manager and onto paper exactly as shown (lower case).

2. Check a backup copy against a key-check record

PASS proves this copy is the key that sealed the record, so it can decrypt the data. FAIL: nothing is wrong with the data; compare your copies character by character and do not retry the release step until the difference is found.
