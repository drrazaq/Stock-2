## Execution contract

The new library has no CLI, scheduled trigger, dynamic binding-module import, global network client or secret discovery. A separately reviewed future colocated host calls it with trusted workflow context, native directory/run/source pins, the immutable owner approval/reference/entitlement files, explicit clock and HTTP transport. `approvedEnvironmentClients` supplies the concrete identifier mapping without reading the real process environment during offline preparation. Existing `runInactiveNativeWorker` and `startColocatedNativeHost` remain rehearsal-only; adding credentials cannot switch either to this entry point. Installing or connecting a production host is not implied by this package.

The supplied context is a trusted-host input, not an independently authenticated assertion merely because a caller constructs a JavaScript object. The guard cross-checks the exact reviewed workflow commit/bytes, both checkout HEADs, every dependency and actual read-only GitHub run history. The future installation must preserve that trust boundary and review the exact host/workflow source and bindings. Owner approval is an immutable reviewed artifact, not a cryptographic signature inferred from JSON booleans.

At capture warmup (not producer launch), unsecreted guard checks precede control binding access. Capture history must establish exactly one authorized attempt; caller-supplied history is ignored. Bounded same-day producer history is then authenticated. Unknown/missing/ambiguous earlier history remains UNKNOWN; available original prefixes and interrupted bytes remain retained in the encrypted journal. A later observation never becomes original ingestion. Source history completeness and heartbeat coverage remain separate.
