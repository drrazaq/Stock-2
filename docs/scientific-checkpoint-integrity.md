# Scientific checkpoint integrity and finite paper arithmetic

The watcher now explicitly requests requireResearch validation before treating a resumed checkpoint as usable. Missing/malformed discovery objects, counters, chronology, quote records and quote-evidence containers cannot enable resumed outbound alerts or masquerade as an uninterrupted scientific session. Invalid checkpoints follow the existing research-only cold-resume path; approved sends remain suppressed. A128MiB input-size bound is checked before parsing. The legacy helper default remains compatible for callers that do not claim research continuity; the actual watcher opts into strict validation. Files are not mutated by rejection.

Three regressions cover malformed/missing scientific state, sparse oversized input and actual watcher opt-in. Existing real-watcher full-session/half-day and hosted artifact transfer fixtures must still pass; helper shape checks alone do not establish deployment reliability. The stricter state check does not authenticate provider/identity sources or guarantee upload recovery.

Paper evidence rejects unsafe integer quantities and nonfinite equity/return arithmetic. Two fault cases verify that finite-but-extreme input cannot generate an infinite resolved paper position/profit. Registered V1 fees, horizon, sizing formula and frozen outcomes are unchanged; bad arithmetic remains blocked/unresolved, never imputed as a gain or loss. No actual prospective result, fill or strategy verdict is produced. Phase A remains the reviewed old7dd702d runtime and exact existing workflow; these development changes are not silently included.
