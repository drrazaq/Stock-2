# Exact signed-request resumption (inactive)

This is a local operator procedure for a previously approved store/authority; it authorizes no setup, real signature, financial mutation, legacy migration or pilot activation. Synthetic inline authorization remains test-only.

1. Inspect the existing store's `head()`, `recoveryView()` and `generationAttempt()` read-only. Verify enrolled authority, source/code/cohort/contract, current expected head and complete pending/residue inventory. No age-based lock deletion. Existing non-test rootless stores remain blocked for separate review.
2. Obtain an independently authorized exact signed request through the approved private custody channel. Retain the original JSON bytes in a private 0700 directory, 0600 regular single-link file, no symlinks. Pin its SHA256. Do not use the old writer token as recovery authority or reconstruct unknown fields. Caller supplies `authorizationSource:{directory,file,sha256}`; the worker verifies the bytes/signature/context and flushes source file+directory before any generation control mutation.
3. The worker preserves the exact request as `takeover-request-<requestHash>.json` before the first generation attempt. `requestHash` binds normalized body/signature AND original raw hash. Changed formatting/fields is not an identical retry. A different signed request cannot replace a reserved attempt. Kernel flock serializes actual control publication and rechecks the expected head.
4. If interrupted **during the request archive write**, preserve its `.control-*` fragment. `generationAttempt()` returns `ORIGINAL_REQUEST_REQUIRED`; retry `recoverUnresolved({authorizationSource:exactOriginalRef})` or the corresponding signed claim with the same source pin. The external original was durably flushed first. If missing/unverifiable, STOP unresolved; no deletion, guessed re-signing or competing takeover.
5. If interrupted **after request archival or during the first generation record**, discovery returns `RECORDED_REQUEST` with generation/attemptHash. `resumeClaim({generation,attemptHash})` reads the exact archived request and validates it. Canonical `RECORDED` attempts use the same resume operation. Every torn fragment remains retained; same-owner exact replay alone can finish. Ambiguous/conflicting archive/control evidence blocks.
6. Verify `GENERATION_READY`, exact generation/owner/request pin and completion receipt; old token must be stale. Any disposed missing original stays permanently UNRESOLVED, cannot be refilled under its old logical ID, and prevents genuine evaluation/admission. New context may be retained only as separately labelled secondary evidence.
7. A failed importer append returns UNKNOWN, never a successful card/recording claim. Inspect pending evidence. Exact same pinned import request/originals may retry an append to recover its identical intent; the regression preserves that intent and all raw source bytes. Missing bytes require the separate authorized unresolved transition above. Do not regenerate a request or rewrite existing outcomes to clear a pending state.

Limits remain 16MiB total store, 2000 files, 15s worker timeout; signed source <=1MiB. Exceeding a cap is a refusal, not permission to raise limits or discard evidence. Resumption cannot prove physical power-loss guarantees beyond successful filesystem fsync, trusted storage and preserved external custody; neither signature nor replay reconstructs absent original source truth.
