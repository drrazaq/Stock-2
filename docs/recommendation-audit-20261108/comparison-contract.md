## Comparator 1: same security, no new bullish source mention before that open

For each retained primary attempt j in security s, construct calendar opens U as follows: u's preceding regular-session open v must itself be inside the publication interval, and u must be no later than the first regular-session open after that interval. For the current calendar U has 22 potential opens, 2 October–2 November inclusive. These are candidate dates, not 22 proven controls.

Membership at u requires authenticated source coverage proving no explicit bullish mention of s in [v,u). A bullish mention anywhere in that interval excludes u, including one with an unmet source condition. Exact-u publication is outside that interval and cannot alter the decision at u; it is retained in the source ledger. Ambiguous timing or a source gap makes membership UNKNOWN. Do not use later recommendations, returns, later halts, later liquidity or earnings to exclude a date.

Apply the same instrument/research-scope rules as to the attempt, using only facts available by u. A security not yet listed is a proved ineligible date; missing historical listing/eligibility facts are UNKNOWN. No hindsight survivor screen. The treatment date should be excluded by its preceding bullish source interval in the usual after-close case; if a before-open exact-boundary case differs, apply these literal intervals, not an extra discretionary removal.

For every proved eligible u use the identical $1,000 whole-share/cash execution, session-20 expiry, costs, corporate actions and unresolved-chain rules as j. Within this comparator each date is an independent hypothetical unit, even when windows overlap; this is not an achievable portfolio of overlapping holdings. Equal weight ALL proved eligible dates: C_stock(j)=sum(R(s,u))/|U_s|. No random sampling, nearest-date draw, return matching, market-state bands or favorable fallback. Empty or materially unknown membership/outcomes => comparator INCONCLUSIVE; never normalize over available successes.

This estimates **the same security on dates without a new bullish source mention immediately before the open**, not 20 recommendation-free sessions or a causal effect. Old or subsequent recommendations can contaminate controls; show all overlaps without filtering them away. Repeated treatment attempts on s share controls and are dependent.
