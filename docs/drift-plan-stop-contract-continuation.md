# Drift entry-to-stop contract correction — development only

EXEC-03 comparison found a real divergence in the existing earnings/event recording path. Both frozen study walkers use the reaction-day low×0.995 as the fixed stop, skip entries whose original-stop risk exceeds15%, and enter at the next open subject to the3% gap ceiling. The renderer’s `planFor` instead shifted that stop by the owner-reported fill’s difference from the source close.

A synthetic source close10.00/stop9.00 and fill10.20 became stop9.20. Running the actual frozen `tradeMA` functions on a synthetic path with low9.10 proves the difference: the shifted stop exits immediately, while the registered9.00stop survives to the40th-session close. This is a contract defect, not new performance evidence.

The development repair preserves the original source stop for **new earnings/event fill records**, checks the existing15% risk limit at the reported entry, and keeps the existing entry ceiling/20-day average/holding rules. A fill outside the registered risk is recorded truthfully with an unresolved strategy plan and retained source/variant metadata, rather than an invented compliant stop. Explicit owner stops remain recordable and are labelled OWNER_STOP_OVERRIDE, not a registered-study result. New original-plan snapshots retain the variant for later accounting/audit; no historical holding, trade, journal, encrypted balance, source artifact or frozen result is rewritten.

The actual command, saved position, original-plan snapshot and acknowledgement are tested with synthetic local fixtures.35cases pass; the old source fails6defect cases and passes29controls. Both actual frozen study functions are exercised without running study mode or changing model/data files. Existing manual/quick/Horizons and LEADER DIP/accounting recovery controls remain in the full suite. No real command, message, fill, order or account access occurred.

This is **not** an endorsement of either strategy or a mentor adapter. Source identity, genuine entry timing, executable BBO/size, fees/slippage/liquidity and independent prospective evidence remain unverified. LEADER DIP stays NOT PROVEN. Other lanes, holding/exit reminders and close-versus-next-open consistency still require full EXEC-03 review. The existing live source producer rounds its stop to two decimals while the study walker uses the unrounded product; that separate tick/rounding execution variant remains unauthenticated. This repair removes fill translation, not every difference between a source plan and historical execution. Legacy unresolved-plan performance attribution also remains unauthenticated; this fix does not silently reclassify historical accounting populations.

This repair is a separate development commit and is **outside** the unchanged seven-file native SEC shadow proposal. Production accounting/watchers remain deployed as previously recorded; this plan correction is not deployed.
