## Implementation and failure contracts

`sec-selection-telemetry.mjs` is default-off, six-name scoped, local-only:≤4096immutable records,≤16KiB/record,≤16MiB/run. An enabled producer writes an immutable RUN_STARTED record even before a scoped event; absence of events does not itself establish source coverage. Validate once on open/restart; subsequent exclusive append is bounded. Stale competing cursors, partial writes, symlinks, caps or invalid clocks quarantine the telemetry and retain committed bytes. Failures do not throw into the observing watcher; source observation/native archiving and existing decisions continue. Raw native feed records retain unmapped/outside-scope entries, with explicit occurrence counters; the selection sidecar is not a whole-market event archive. Partial native/source coverage remains uncertainty.

The actual watcher patch adds **0provider requests**, no scoring/message/producer-order change and no workflow activation. It preserves source failures, including a body-read failure, rather than calling them empty. The exact production test harness supplies the real disabled observer for old function-extraction tests; original assertions remain. The shared Sunday RECORDS test fix is separately hashed and concerns test section boundaries only.

`sec-proof-ready-proposal.mjs` reads the persisted native and telemetry paths, verifies matching raw proof and trigger origin, and requires a reader-minted handle before quote observation. Provider requests must start after that read; response time is bounded10seconds, and source-read clocks may not regress across frames. Native/telemetry prefixes must be stable and no later than the actual source read; combined source context≤8MiB. Actual-format `frameFromSnapshots` inputs retain quote clocks, previous-session basis and contiguous liquidity bounds. Invariant matching-pool uncertainty, stale/before-readiness BBOs, missing size, moved controls, revisions/conflicts, unknown history or unavailable matching proof prevent a proposed pair. Draft3 state preserves the first source-readiness clock/proof/revision even when no pair was available. A later read cannot refresh the three-minute expiry; a consumed handle cannot be reused. State is versioned/checksummed; sequence/assignment checks prevent restart duplicates. Checksums are integrity checks, not source authentication.

**The prototype never admits a case:** policyApproved=false, primaryAdmission=false, genuineAdmissions=0. It is not wired into the approved binding or frozen evaluator. All no-request/deferred/excluded events/reasons remain visible; first-ingestion and source bytes are never backfilled. Existing historical archives/results are untouched; October28pilot and October29 stay excluded from primary ranking.
