# Frozen coverage contract R-A1

This request is deliberately **coverage-only**, not permission to run the outcome study. It makes no signal/return comparison and does not call a daily bar executable. CONTRACT.json fixes the proposed cap-free daily rule **before authentic cache observation**, so later data cannot justify a new threshold. A market outcome evaluator is not activated or claimed completed by this package. The analyzer has no signal/return function and never emits PASS: legacy cache provenance cannot be authenticated from the numeric arrays alone. This limitation is explicit, not a disguised profitable backtest or a promise a boolean sidecar will cure it.

Why a bounded observation can still help: cache presence, actual first/last session, session count, parallel-field integrity, x-tail coverage, invalid rows, duplicate ticker-days and sizes have not been observed here. Schedules do not establish them. One exact retained cache version can settle these facts where it resides. Coverage reading numeric fields for validity is distinct from calculating or inspecting event-to-outcome returns; the latter is absent. If the owner wants only an economically executable study, **do not authorize this run as sufficient**: it cannot alone deliver one. No analysis phase starts automatically.

## Inputs and limits

- Existing `leaders-study-*` **main-scope** cache: select latest metadata `created_at`, tie by ID, never by returns or size convenience. At most2 GitHub metadata pages,100 rows/page,1MiB/page. If list incomplete, newest cache oversized, removed, incompatible or missing, stop; no older fallback or prefix restore. Full actual cache key is passed to restore-only and exact readback checked.
- Only `study-cache/grouped.json.gz` is parsed. Compressed file≤256MiB, decompressed JSON≤1GiB,1600 sessions/12m rows/16k ticker labels,CPU180sec/address-space4GiB. All are hard abort thresholds, not sampling caps; no partial subset is substituted.
- Fixed requested warmup3Jan2022, formations3Jan2023–30Sep2026, outcomes through30Oct2026, older/newer split1Jan2024. Range presence does not prove every required regular session. A genuinely sourced session calendar is needed to validate holes; do not label missing weekdays holidays automatically.
- Cache source at7db/ed824 writes parallel `T,o,h,l,c,v` plus some `x` tails. It builds a current/refreshed CS/ADRC membership list, not a proven dated ordinary-stock master. x-tail presence does not establish all extinct issuers or delisting settlements. Its heuristic split repair does not reconstruct raw dollar prices, original volume basis or cash dividends. The analyzer reports these as unauthenticated rather than manufacturing a trade quantity or fee return.
- Original receipts, PIT security/class history, dead-firm membership, raw/adjusted factor chain, actual settlement/no-fill evidence and same-industry controls remain separately required. Historical cap remains UNKNOWN. Unknown identity is not guessed or dropped from counts. Ticker counts are not company counts.
