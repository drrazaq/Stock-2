# Regular-session paper quote evidence (branch only)

The watcher now records actually observed normalized bid/ask quotes alongside discovery events, independently of selected last-trade clocks. No extra provider call, Telegram, order, strategy promotion or lab invocation is added. The recorder persists inside DISCOVERY state, so the existing same-source checkpoint transfers its bounded evidence across watcher jobs. At completion it writes an immutable run-specific compressed paper-input artifact under the existing discovery-runs archive. Production is not deployed.

The source input data/research-security-identities.json is optional and not created or modified by engineering. It requires records with symbol/securityId/issuerCik, knownAt/validFrom/validTo, HTTPS evidence and industry. Mapping shape is not source authenticity. Metadata asOf records actual first ingestion, including premarket, never reconstructed publication availability. Ambiguous/missing identity is null; late metadata cannot backfill an earlier detection. Only explicitly declared eligibleControl records join capture targets, alongside candidates and SPY. Control declaration alone cannot establish valid industry/liquidity matching.

Bid/ask must be positive, uncrossed and independently clocked within120seconds. A fresh last trade cannot refresh a stale BBO. Dollar volume requires its own explicit same-session clock within15minutes; last-price times cumulative shares is never silently substituted. Unknown liquidity remains null, so the paper evaluator blocks entry. Captured entry/control/exit rows must match the same securityId. Fresh quotes are paper assumptions, not observed fills. Target/missing/conflicting row counts and limits remain explicit.

Limits:1000 event IDs,250 target symbols/cycle,30000 quote rows,2000 metadata records. Capture includes the first36minutes after detection or market open, bounded by reviewed regular/half-day close. Missing targets, stale BBOs, ambiguity, dropped data and duplicate/retrograde cycles remain counters, not repaired prices. Budget-limited samples cannot be claimed complete. No actual prospective case exists yet.

Seven fixture regressions cover price/quote clock separation, identity/liquidity unknowns, JSON checkpoint restoration, half-day/premarket/budget boundaries, declared matched controls, conflicting/missing rows and premarket metadata timing. Matched fixture outcomes are explicitly simulations. Authorized live observation, verified point-in-time metadata/denominator, continuous horizon/spread/capacity coverage, real matched/benchmark comparisons and profitability remain acceptance blockers. Phase A is still the unchanged old7dd702d source; this newer recorder is not silently included in it.
