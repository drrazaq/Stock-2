## Completeness, budgets and recovery

A supplied limits object is mandatory: hard ceiling32 attempts per collector instance, ≤1MiB body, ≤8MiB aggregate received bytes, ≤20s HTTP body deadline and ≤600s active instance. These are **engineering ceilings, not an approved collection scope**. The SIP interval is at most30s, with at most10s early startup and ≤1s shutdown margin, bounded by the instance deadline; the HTTP20s ceiling is not applied to a full30s streaming window. The new private store has a **16MiB total** ceiling including control/journal/record/raw bytes and at most2,000 files. Overhead means useful raw capacity is lower; no assurance that8MiB raw fits. Fail closed rather than increasing limits. This does not alter IG1's156-request,112MiB effective raw/160MiB sealed limits.

Each logical window gets a durable request reservation before its transport starts. If a process dies before a frame is committed, a new instance cannot silently redial: an earlier unresolved request produces INCOMPLETE. Completed frames can be reused across restarts without new requests, after exact context comparison. There is no automatic backfill/replacement. Raw oversized bodies retain a labelled bounded prefix; bytes beyond the hard cap are unavailable, never treated as complete. Provider errors are private originals; public errors remain fixed codes.

Kernel lock files are never removed or expired. Cooperative claims serialize and CAS the expected generation; old generations fail before writing. A reproduced Node24 contention race (terminal lock refusal plus stdin EPIPE) is fixed with a dedicated flock conflict exit73 checked before generic process errors; only that definitive no-start result is BUSY. Unexpected failures stay UNKNOWN. Every generation is immutable; only HEAD is a mutable, atomically renamed control pointer. Partial temp files are retained, never truncated. A torn/corrupt record, absent original, replaced lock/root, cap exhaustion or unknown write refuses; no blind retry. Read head/intent/commit evidence to reconcile the exact attempted operation. A fresh generation cannot bypass pending intents. No external publication exists: `LOCAL_DURABLE_COMMIT` is **local**, never an upload receipt.
