No reset/force-push, historical tree restore or broad PR revert. A conflict requires reconciliation; do not overwrite unrelated work. If state uncertainty prevents a safe abort/resumption, report an incident **immediately**, with exact workflow states and failed action, before the deadline; no financial reconciliation or unsafe automatic re-enable is authorized. A fixed deadline is not permission to discard state. This failure contingency must be agreed before maintenance; it is why the readiness gate is mandatory.
