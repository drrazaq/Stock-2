# Offline hybrid session contract

This new module is a pure observation/fixture admission layer, not a live collector. No fetch, secret, CLI, order or Telegram code is added. It freezes provider IDs and current active/tradable US-equity reference rows as-known, but explicitly cannot authenticate historical identity, SEC CIKs or whole-market completeness. Conflicting provider IDs/aliases and future references fail closed; exact duplicates are counted. A change after session start is rejected rather than replacing the earlier denominator.

A plan computes every explicit snapshot batch, cycle and reserved request, refuses insufficient budget/pacing and states that actual batch capacity and live authority are unverified. No networking is performed; real request cancellation, streaming-byte limits, retries and encrypted checkpoints are intentionally not claimed implemented. An actual collector must separately enforce them and establish exact source/workflow approval.

Each supplied observation contains batch index, feed, request/receipt clocks, HTTP status and a symbol map. Wrong feed, old/future receipts, duplicated batches, unsolicited symbols and malformed rows do not establish coverage. Future trade/BBO clocks at receipt remain invalid when the sweep later completes. Clock-window completeness is distinct from every declared symbol returned; fresh trades and BBOs use separate180s/120s windows and the entire declared universe as denominator. P95 ages include stale known clocks, not just fresh successes. Missing/failure observations accumulate across the session rather than disappearing behind a later success. Delayed rows never supply missing SIP prices; only explicitly unverified previous-close context may accompany actual observed SIP rows.

The existing research-only discovery runtime retains first ingestion time/price and subsequent actually observed crossings; delayed reports are not backdated. Cached lane availability/staleness is retained. The full330-minute fixture has one feed-interruption sweep: clockWindowComplete=true, allDeclaredSweepsReturned=false. This is a test result, not observed live performance. No fill, profitability, independent identity, survivor-free universe or approved BUY follows.
