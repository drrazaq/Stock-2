## What you can obtain

**Read-only repository metadata on1November confirms Stock-2 is PUBLIC.** Do not describe artifact access as private merely because the bytes are encrypted. This checklist requests contractual permission for the actual storage/access arrangement; it proposes no private-state migration.

One redacted capture of the subscription screen plus one official entitlement/terms confirmation may cover this entire checklist. Use the Alpaca dashboard’s **market-data subscription/product details** or an official Alpaca support response. Dashboard labels can change: include the actual page heading/URL and capture date; do not guess a plan from a public pricing page. If a field is absent, write **NOT SHOWN** and obtain official confirmation rather than inferring yes.

- [ ] **Product and active entitlement:** exact subscribed product/plan name; Trading API versus Broker API product; subscription status; effective date and any expiry/end date; capture date/time and timezone. Billing amount, payment details and account number are unnecessary.
- [ ] **Feed:** explicit right to **latest real-time SIP consolidated US-equity quotes and trades**, including both CTA/UTP coverage as applicable; distinguish `sip`, `iex` and `delayed_sip`. A label “historical data” is insufficient. Confirm this applies to the existing data integration/environment without supplying any key or key identifier.
- [ ] **Names and sessions:** current access for **AMD, INTC, NVDA, AMAT, LRCX, KLAC**, regular09:30–16:00New York session. State any instrument/exchange/symbol exclusions. Premarket/extended-hours rights should be stated separately if available; this calibration does not require or prove whole-market/premarket surveillance.
- [ ] **Exact snapshot route:** entitlement to `GET https://data.alpaca.markets/v2/stocks/snapshots` with these six `symbols` and explicit `feed=sip`; latestQuote, latestTrade, minuteBar and prevDailyBar. No order/account-balance endpoint is proposed.
- [ ] **Rate/batch allocation:** account-specific requests/minute, six-symbol batch limit and permitted concurrency; whether limits are shared across keys/endpoints and existing production jobs. The proposal adds≤41snapshot attempts,1in flight, at most2in a rolling60seconds at its final boundary. Existing traffic also consumes headroom; a rate header alone is not a contractual allocation.
- [ ] **Quote semantics:** current `latestQuote.bp/ap`, `bs/as` units, quote timestamp/tape/conditions and what establishes a firm/non-halted executable BBO. Public documentation distinguishes current share-size units from older round-lot data. Freshness alone does not establish availability, halt status or an execution.
- [ ] **Bar semantics:** minuteBar timestamp/volume units, completed versus partial minutes, late/corrected trade treatment and revision behavior; prevDailyBar session/date and split/corporate-action adjustment basis. These determine cumulative-dollar-volume bounds and the previous-session D predicates. Unknown adjustment/session basis remains unresolved.
- [ ] **License/use:** permission for unattended internal research/paper analysis; applicable professional/nonprofessional classification; storage/replay of raw responses, quote-derived telemetry and references. Confirm encrypted storage/download/recovery in GitHub Actions for3days and who may access it. Document actual repository/artifact access: encryption does not itself grant redistribution rights or make a public-repository artifact private. No raw market data may be publicly committed.
- [ ] **Reference route:** whether the existing environment may use read-only `GET https://paper-api.alpaca.markets/v2/assets/{symbol}` for these six names. `active/us_equity/tradable` alone is not authoritative common-stock identity or historical membership. No broker order is proposed.

## Other reference evidence, separately from SIP rights

- [ ] **Massive reference entitlement/terms:** permission for up to6read-only ticker-detail responses at `/v3/reference/tickers/{symbol}`, with symbol/class/type, stable security identifier (e.g. FIGI), issuer CIK, exchange, as-of/known-at clocks and retention rights. Do not infer class from a ticker suffix or substitute dash/dot aliases. Starter’s delayed prices do not become real-time because its reference endpoint works.
- [ ] **SEC source semantics:** official matched CIK/accession and literal submissions `acceptanceDateTime`/SIC, with original request/receipt bytes/clocks. Atom `updated` is not acceptance. Missing CIK does not prove a warrant, debt or resale filing. Six separately approved submissions calls are only a reference-preparation maximum; no new proof requests are authorized.
- [ ] **Freshness/provenance:** dated original exports or captures and actual receipt/known-at clocks; conflicting identifiers/class/SIC remain unknown. A later export cannot be backdated to before detection. No new API calls should be made to satisfy this checklist without their specific approval; existing exports or official written confirmation are acceptable preparation inputs.

## What to redact and what is not requested

**Do not provide credentials, tokens, private keys, account IDs, balances, holdings, orders, payment/card information, email/address or support-ticket identifiers.** Keep only provider/product/rights/schema/quota/retention wording, relevant dates, source page heading/URL and the six public symbols. Redact both screenshots and downloaded document metadata where necessary. None of these documents authorizes purchases, subscription changes, binding installation, collection or deployment.
