# News source bounded-read continuation — development only

A remaining CATALYST-03/MARKET-03 ingress defect is repaired in a separate commit from the inactive native SEC package. Before the repair, a valid news JSON array padded beyond2MiB was reported OBSERVED, an invalid explicit observation clock could yield OBSERVED empty, and a fetch ignoring AbortSignal remained pending. The same synthetic controls now return BODY_LIMIT, INVALID_OBSERVATION_CLOCK and TIMEOUT. This changes neither research enrollment nor strategy/compliance gates.

`news-source.mjs` now counts actual streamed bytes (2MiB maximum), rejects more than20,000 rows, validates UTF-8 and supplied observation clocks, and bounds the whole fetch/body read by15seconds independently of cooperative abort. It cancels over-budget/stalled bodies without awaiting a stalled cancellation and adds no retry. Missing/unavailable/over-budget source data has `rows:null`; it cannot become genuinely empty news. Valid siblings, explicit successful empty arrays and received/rejected counts remain available. Original request/header/body receipt clocks are separate; the default observed clock is actual body completion, never source publication time. Row publication remains Finnhub epoch **seconds**; no quote or trade timestamp refreshes it.

Six new synthetic regressions include the exact `news-watch.mjs::fh` caller: an oversized source does not enter revision handling, save delivery state or produce a result row. Existing reconstructed source tests retain their assertions and now use actual Response stream objects for successful payloads. The previous lost test was **reconstructed, not recovered**. The existing full news delivery/restart/refusal controls are run by the normal full suite; this is not a duplicate all-route delivery audit.

No source truncation is labelled complete. The actual caller records the new failure status and exits nonzero under its existing unavailable-source rule. Diagnostic reason/status and clock evidence do not include the credential-bearing request URL. No provider request or real message was executed for verification. This code is branch-only and is **not included** in the separate seven-file native SEC shadow proposal; production is unchanged.

Remaining engineering is explicit: metadata/profile/quote paths still use legacy nullable responses; other providers/sources need their own body/session/alias/corporate-action contracts; all delivered plans still need exact registered entry/stop/exit/cost/size/liquidity comparison. CATALYST-03, MARKET-03 and EXEC-03 remain OPEN. This source bound is not an acceptance closure or proof of economic materiality, source authenticity, execution or profitability.
